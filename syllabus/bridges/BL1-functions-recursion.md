# BL1: Functions, Stack Frames, and Simple Recursion
**Purpose:** Smooth jump from basic Python to tracing code and recursion (needed before deeper DS/algos).

## Resources
- Automate the Boring Stuff (ATBS) ch.3 “Functions”: https://automatetheboringstuff.com/2e/chapter3/
- CS50 call stack primer (clip): https://www.youtube.com/watch?v=7EmboKQH8lM
- Optional: CS50 2023 functions segment (~15m): https://youtu.be/YoZPTyGL2IQ?t=200

## Tasks
- Write: Iterative factorial and recursive factorial; recursive Fibonacci (small n).
- Trace: On paper, show call stack push/pop for factorial(4) and fib(5).
- Add: One function that calls another and returns a composed value (to see stack behavior).

## Knowledge Check
- Define “base case” and what happens if you omit it.
- Explain where local variables live during a function call.
- Describe when recursion is a bad fit (stack depth/perf) vs when it’s fine (tree/graph traversals).

## Exit Criteria
- You can trace a recursive function step-by-step and predict output.
- You can explain why recursion stops and what would cause a stack overflow.
