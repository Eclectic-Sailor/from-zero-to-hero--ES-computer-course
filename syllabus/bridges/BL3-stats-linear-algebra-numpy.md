# BL3: Stats/Prob & Linear Algebra Lite + NumPy/Pandas On-Ramp (Pre-ML)
**Purpose:** Prepare for ML lessons with minimal math and tooling.

## Resources
- StatQuest mean/variance video: https://www.youtube.com/watch?v=xxpc-HPKN28
- Seeing Theory conditional probability (interactive): https://seeing-theory.brown.edu/basic-probability/index.html
- 3Blue1Brown “Essence of Linear Algebra” #1–#3: https://www.youtube.com/playlist?list=PLZHQObOWTQDNU6R1_67000Dx_ZCJB-3pi
- NumPy quickstart: https://numpy.org/doc/stable/user/quickstart.html
- Pandas 10-minute intro: https://pandas.pydata.org/pandas-docs/stable/user_guide/10min.html

## Tasks
- Compute by hand: mean, variance of a 5-number list; conditional probability simple example.
- Linear algebra: do a 2×2 times 2×1 multiply by hand; compute a dot product by hand and with `np.dot`.
- NumPy: create arrays, reshape, slice; perform vectorized add/multiply; compute dot product.
- Pandas: load a CSV (any small public dataset), show `.head()`, `.describe()`, select/filter rows.

## Knowledge Check
- Explain overfitting risk in one sentence (ties to variance).
- Describe what a dot product represents.
- Show how `train_test_split` conceptually works (even if not coding yet).

## Exit Criteria
- You can manipulate NumPy arrays and basic Pandas DataFrames.
- You can explain mean/variance and perform a simple matrix multiply.
