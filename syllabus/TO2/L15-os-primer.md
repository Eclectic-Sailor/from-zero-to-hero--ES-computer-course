# L15: OS Primer (EO4)
**Objectives:** Understand processes vs threads, scheduling concept, virtual memory basics.

## Resources
- Read: “Operating Systems: Three Easy Pieces” (OSTEP) Intro + CPU scheduling: https://pages.cs.wisc.edu/~remzi/OSTEP/
- Watch: OS intro lecture (Neso Academy OS playlist first video): https://www.youtube.com/watch?v=8X69_42Mj-g

## Tasks
- Write short answers: what is a process? a thread? context switch?
- Use your OS tools: list processes (`ps`, `top`, or Task Manager).
- Map virtual vs physical memory conceptually (no code).

## Example to Analyze
- Consider two threads writing to the same variable without locks. What hazard arises?

## Knowledge Check
- Why do we need scheduling?
- What is a race condition?
- What does the OS do when you run a program (high-level)?

## Exit Criteria
- Written answers to 5 OS concept questions (process, thread, context switch, virtual memory, race condition).
- You can explain why threads can be faster and also riskier.
