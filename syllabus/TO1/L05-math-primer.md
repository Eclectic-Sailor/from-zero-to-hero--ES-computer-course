# L05: Math Primer (EO4)
**Objectives:** Basic logic, sets, simple counting/probability.

## Resources
- MIT OCW 6.042J notes on logic/sets: https://ocw.mit.edu/courses/6-042j-mathematics-for-computer-science-fall-2010/resources/mit6_042jf10_notes/
- Seeing Theory probability basics (interactive): https://seeing-theory.brown.edu/basic-probability/index.html
- StatQuest combinations/permutations video: https://www.youtube.com/watch?v=8RRo6Ti9d0U

## Tasks
- Build truth tables for 3 expressions (AND/OR/NOT, implication).
- Set practice: union/intersection/difference on small sets; Venn reasoning.
- Counting: compute permutations (order matters) vs combinations (order not) for small n,k.

## Example Problems
- How many 3-letter strings can you form from ABCD without repetition?
- Given 10 items, how many ways to choose 3 regardless of order?

## Knowledge Check
- Difference between implication and equivalence.
- When do you multiply probabilities vs add them (independent vs mutually exclusive)?

## Exit Criteria
- Solve 3 counting questions correctly.
- Explain set union vs intersection with a concrete example.
