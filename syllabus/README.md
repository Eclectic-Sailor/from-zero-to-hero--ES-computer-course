# Blended CS/Security/SE Syllabus

Shareable roadmap covering foundations (TO1), core undergrad depth (TO2), and advanced/grad-flavor topics (TO3). Bridge lessons (BL) fill gaps between phases. Resources are free and include articles, videos, and guided projects. Languages prioritized: Python → C → Java → others optional.

## Structure
- `RESOURCES.md`: Canonical links for books/articles, videos, and guided projects.
- `bridges/BL*.md`: Gap fillers between phases (tooling, pointers, math/NumPy, Docker/auth).
- `TO1/`: Foundations lessons (L1–L9).
- `TO2/`: Core undergrad lessons (L10–L19).
- `TO3/`: Advanced lessons (L20–L35).

## How to use
- Each lesson has objectives (EOs), resources with sections/timestamps, tasks, knowledge checks, and exit criteria. Use `RESOURCES.md` for quick links.
- Flex weekly hours; if short on time, do resources → one practice task → knowledge check → exit.
- Keep a learning journal (time spent, blockers, what you learned).
- Pair up: review each other’s knowledge checks and exit artifacts (code, notes, screenshots).

## Terminal Objectives
- **TO1 Foundations**: Comfortable scripting, basic CS/math/security, simple web/SQL.
- **TO2 Core Undergrad Depth**: Data structures/algos, C/Java basics, OS/net/DB fundamentals, secure web coding, small REST service.
- **TO3 Advanced/Grad-Flavor**: ML/analytics basics, distributed systems, containers/K8s, testing/CI/CD, DDD, DevSecOps, auth/IR, observability, capstone.

## Bridge Lessons
- BL0: Tooling setup (before anything else).
- BL1: Functions/recursion/stack frames (after TO1 L03, before deeper DS/algos).
- BL2: Binary/hex, memory, pointers concept (before TO2 L13 C basics).
- BL3: Stats/probability + linear algebra lite; NumPy/Pandas basics (before TO3 ML lessons L20–L21).
- BL4: Docker 101; session vs token vs JWT; simple JWT flow (before TO3 containers/auth lessons L25+ and L30).
